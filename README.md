# Ecommerce Product Research Skills

This repo packages the main `product-market-researcher` skill plus its helper skills.

Main entry:

- `product-market-researcher/`

Included helper skills:

- `amazon-product-scraper/`
- `apify-amazon-scraper/`
- `apify-tiktok-scraper/`
- `apify-market-scraper/`
- `profit-model-builder/`
- `report-generator/`
- `market-intelligence/`
- `tiktok-analytics/`

Secrets and local paths are intentionally removed from the public copy. Use the `.env.example` files and environment variables documented inside each skill folder.
