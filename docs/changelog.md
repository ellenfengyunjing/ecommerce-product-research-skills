## 提交规范

提交信息格式:
```
<类型>: <描述>

[可选的详细说明]
```

类型:
- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更新
- `style`: 代码格式
- `refactor`: 重构
- `test`: 测试
- `chore`: 维护

示例:
```
feat: 添加多市场支持

添加对英国、德国市场的完整支持，
包括本地化关键词和价格区间。
```
